L6 · Composition Plan

This plan documents each positioned, layered, clipped, rounded, or shape-wrapped element used in The Forgotten Handheld. Rows are updated as each enhancement is implemented and tested.

Element Content purpose Normal-flow baseline Chosen technique and why Containing block / stacking context Fallback or disengagement Required test
Header generation badge Identifies the time span and three-generation focus of the Game Boy feature without interrupting the main headline or introduction. Appears as an inline-block between the headline and lede when positioning is not applied. At the 52rem enhancement breakpoint, the feature header becomes the positioned parent and the badge uses absolute positioning with logical inset properties to anchor it to the header's top-right corner. The feature header uses position: relative and establishes the containing block for the absolutely positioned badge. The badge does not receive a z-index because no competing layer overlaps it. Below the 52rem enhancement breakpoint, absolute positioning disengages and the badge returns to normal flow. At 52rem and above, it anchors to the feature header's top-right corner. Test at 320px, 768px, and 1280px widths and at 200% zoom. Test immediately below and above the 52rem breakpoint. Confirm the badge never covers the title or lede.
Sticky generation story guide Keeps navigation to the four Game Boy story sections available while the reader moves through the longer feature. Appears before the article as a normal-flow navigation block when the page uses its single-column layout. At the 52rem breakpoint, CSS Grid creates a dedicated navigation column beside the article. The story guide then uses position: sticky with a logical block-start offset so the navigation remains available while the article scrolls. The story guide occupies the first column of the main grid and uses position: sticky with z-index: var(--layer-sticky). This places the interactive navigation above the overlapping pull quote so its links remain visible and pointer accessible. Below the 52rem breakpoint, the grid and sticky positioning disengage. The story guide returns to normal document flow above the article. Test at 320px, 768px, and 1280px widths. At desktop width, scroll through the article and confirm the guide remains visible without covering article content. Confirm all four links remain keyboard accessible and clickable. At narrow widths, confirm the guide remains in normal flow.
Overlapping pull quote Emphasizes the feature's central idea that the Game Boy's technical limitations contributed to its visual identity and lasting appeal. Appears as an emphasized paragraph within the original Game Boy section. It remains completely inside the article column with no overlap at narrow widths. At the 52rem breakpoint, a negative inline-start margin pulls the quote across the grid gutter and slightly into the adjacent story-guide column. Relative positioning allows the quote to participate in the controlled L4 stacking relationship. The pull quote remains part of the article's normal flow. Position: relative allows z-index: var(--layer-raised) to place the quote above ordinary page content while keeping it below the interactive sticky story guide. Below the 52rem breakpoint, the negative margin, relative positioning, and raised layer are not applied. The quote returns to its normal single-column presentation. Test at 320px, 768px, and 1280px widths and at 200% zoom. At desktop width, confirm the quote visibly crosses the gutter but does not obscure the story guide's link text or prevent any link from being clicked. Test immediately below and above the 52rem breakpoint.
Decorative header pixel accent Adds a small Game Boy-inspired visual detail to the feature header without communicating information. The decoration does not exist in the HTML source, so removing it has no effect on content, semantics, or reading order. A generated ::after pseudo-element is absolutely positioned along the bottom edge of the feature header. Because the accent is purely decorative, pointer-events: none prevents it from intercepting pointer interaction. The feature header establishes the pseudo-element's containing block. No custom z-index is needed because the decoration does not participate in a competing overlap relationship. If generated content, positioning, or CSS is unsupported or disabled, the accent simply disappears. No information or functionality is lost. Confirm the decoration does not cover header text or the generation badge. Verify pointer interaction with nearby content is unaffected and confirm the page remains complete with CSS disabled.
Game Boy Advance shape-wrapped image Provides visual support for the Game Boy Advance section while creating an editorial relationship between the media and surrounding story text. Displays as a normal responsive block image above the surrounding text before the shape enhancement is applied. At a supported wider viewport, the image itself will float inline-start. Shape-outside and shape-margin will progressively enhance the rectangular float so article text follows a deliberate shape around the media. The image participates in the Game Boy Advance section's flow. The section will contain the float so later sections cannot unexpectedly wrap around it. Any stacking requirements will be documented if they are introduced during implementation. At narrow widths or when shape-outside is unsupported, the float and shape enhancement will disengage. The image will remain a responsive block element and the article text will continue beneath it in source order. Test with shape-outside enabled and disabled and at 320px, 768px, and 1280px widths. Test at 200% zoom and with increased text size. Confirm text never collides with the image or its credit and that later sections clear the floated media correctly.
